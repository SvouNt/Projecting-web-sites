# Разработка программы «Анализ успеваемости»
Распределение задач (роли выделены):
-	Тимлид: Отвечает за архитектуру. Создает файл main.js, импортирует функции из модулей (или просто собирает код). Проверяет Pull Request'ы.
-	Программист 1: Пишет функцию calculateAverage(data), которая вычисляет средний балл.
-	Программист 2: Пишет функцию findTopStudent(data), которая возвращает имя студента с максимальным баллом.
-	Программист 3: Пишет функцию filterFailed(data, passScore), которая возвращает массив имен студентов, чей балл ниже passScore (проходной балл = 60).
-	Программист 4: Пишет функцию addLetterGrade(data), которая добавляет каждому студенту новое поле letter: "A" (>=90), "B" (75-89), "C" (<75).

Все задачи выполняются одним человеком - Карчевским Михаилом Петровичем (ОДБИ-302б)

# Интеграция и Git
1.	Каждый участник завершает свою функцию, коммитит изменения в свою ветку (feature/...) и пушит в удаленный репозиторий.
2.	Каждый участник создает Pull Request (PR) в ветку develop, назначая ревьюером Макара (тимлида).
3.	Макар проверяет код, дает комментарии (при необходимости). Денис помогает проверять сложные участки.
4.	После успешного ревью Макар вливает (merge) изменения в develop.
5.	Финально, Макар создает PR из develop в main и демонстрирует работоспособность итогового скрипта.

# Итоговое задание

В файле report.js (или в конце main.js) тимлид должен собрать вызов всех функций и продемонстрировать их работу через console.log:
1.	Средний балл группы.
2.	Лучший студент.
3.	Список должников (кто не сдал).
4.	Итоговый массив с буквенными оценками.
